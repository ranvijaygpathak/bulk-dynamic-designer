# Bulk Dynamic Designer V4.1

This is a fixed V4 build.

## Import Existing Design

The left **Elements** panel now contains:

**Import Existing Design**

Supported:
- PNG
- JPG/JPEG
- PDF

PNG/JPG are placed as a locked visual background. PDF imports the first page as a visual background.

Then add dynamic fields such as `{{name}}`, `{{father_name}}`, and `{{course}}` on top and map them to Excel.

## Unicode

Font choices include Mangal, Nirmala UI, Noto Sans Devanagari, Noto Serif Devanagari, Hind, Mukta, Kokila, Aparajita and Arial Unicode MS.

Hindi and Bhojpuri written in Devanagari are supported.

Run:
```bash
npm install
npm run dev
```
